# 『Na Pradze i dalej』 — 바르샤바 일상 폴란드어 대화문 시리즈 기획

> 바르샤바 프라가 출신 30대 남자 **쿠바(Jakub "Kuba" Zieliński)** 와 이웃·가족·친구들이
> 2022~2026년 바르샤바에서 실제로 겪은 현안 속에서 작은 문제들을 하나씩 해결해 가는 일상 드라마.

| 항목 | 내용 |
|---|---|
| 배경 | 폴란드 바르샤바 (주무대: 프라가-포우드니에 그로후프 구역) |
| 주인공 | 쿠바 지엘린스키, 1990년 바르샤바 프라가 출생, 1부 시작 시 32세 |
| 분량 | 4부 × 15화 = **60화**, 각 화 **120턴** → 총 **7,200턴** |
| 시간 흐름 | 1부 2022 → 2부 2023 → 3부 2024 → 4부 2025~2026 상반기 (실제 연표와 동기화) |
| 장르 | 생활 밀착형 문제 해결 드라마 (슬라이스 오브 라이프 + 소소한 미스터리/중재) |
| 학습 수준 | 1부 A2→B1, 2부 B1, 3부 B1→B2, 4부 B2 |
| 등장인물 | **대사가 있는 인물은 전원 폴란드인** (외국인은 지문·언급으로만) |
