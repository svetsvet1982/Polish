# 02. 현안 연표 (2021~2026)와 반영 회차

## 허구 처리 원칙

1. **실제 사건 = 배경**. 뉴스 화면, 라디오, 인물의 짧은 대사로 언급한다. 사건의 "숨은 내막"은 전부 허구 인물·허구 조직의 일이다.
2. **실존 인물은 대사 없음**. 대통령·총리·장관·후보는 직함("premier", "kandydat")으로만 언급하고 이름을 쓰지 않는다.
   대선 후보는 가상의 세 후보(아래 3부 참조)로 대체한다.
3. **정당명 사용 금지**. "rządząca koalicja / opozycja"로 처리하고, 1부(2023 정권 교체 전)와 2부 이후의 여야 위치가 바뀌는 것만 반영한다.
4. **2026년(4부)은 가상의 시간**. 실제 2026년 사건과 무관한 허구 전개로 명시한다.
5. 날짜·수치는 기획 시점 자료 기준. 집필 단계에서 재확인한다.
