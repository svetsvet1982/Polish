# 『Szara strefa』 (회색지대) — 폴란드어 정통 정치첩보 스릴러 대화문 시리즈 기획

> 2021년 벨라루스 국경에서 정보원을 잃고 방첩기관을 떠난 바르샤바 토박이 **아담 루드니츠키**가
> 비스와강에서 떠오른 시신 한 구를 계기로 다시 '회색지대'로 끌려 들어간다.
> 선거, 사보타주, 허위정보, 포로 교환, 그리고 국가 한가운데 숨은 두더지 **"오르가니스타(Organista)"**.

| 항목 | 내용 |
|---|---|
| 장르 | 정통 정치첩보 스릴러 (르 카레식 심리·절차 중심 + 정치 드라마) |
| 언어 | **대사 전부 폴란드어** (+ 한국어 번역 병기). 외국 국적 인물도 폴란드어로 말하고, 억양·어휘 습관은 지문과 말투 규칙으로 표현 |
| 주인공 | 아담 루드니츠키(Adam Rudnicki), 1980년 바르샤바 무라누프 출생, 1부 시작 시 **42~43세** → 4부 **46세** |
| 분량 | **4부 × 12화 = 48화**, 각 화 **120~150턴** → 총 **6,642턴** (회차별 턴 수는 에피소드 가이드 참조) |
| 시간 흐름 | 프롤로그 2021 → 1부 2023 → 2부 2024 → 3부 2025 → 4부 2026(가상) |
| 현안 반영 | 2021~2025 폴란드 실제 안보·정치 현안을 **배경**으로 사용하고, 사건의 내막·인물은 **전부 허구** |
| 수준 | 원어민 드라마 수준(B2~C1). 1부는 비교적 평이, 4부로 갈수록 은어·법률·정보기관 용어 비중 증가 |

## 시리즈 구조 한눈에

| 부 | 제목 | 시기 | 핵심 질문 | 실제 현안 배경 |
|---|---|---|---|---|
| 1부 | **Martwa skrzynka** (데드 드롭) | 2023.3–12 | 2021년에 죽은 줄 알았던 정보원 레나는 살아 있는가? | 철도 감시카메라 간첩망, 바그너 그룹 벨라루스 이동, 비자 스캔들, 10·15 총선, 정권 교체 |
| 2부 | **Kret** (두더지) | 2024.1–12 | 방첩기관 안의 두더지 "오르가니스타"는 누구인가? | 공영방송 장악 논란, 농민·화물 국경 봉쇄, 마리빌스카 화재, 판사 벨라루스 망명, PAP 해킹, 포로 교환, 남서부 대홍수 |
| 3부 | **Wybory** (선거) | 2025.1–12 | 대통령 선거를 노리는 작전 "미그와(Mgła)"를 막을 수 있는가? 그리고 멘토 소바는 누구 편인가? | EU 의장국, 대선, 텔레그램 사보타주 모집, 영사관 폐쇄, 러시아 드론 영공 침범, 철도 폭파 |
| 4부 | **Organista** (오르가니스트) | 2026.1–12 (가상) | 이중·삼중 스파이의 진실, 그리고 국가는 누구를 위해 거짓말하는가? | 가상의 2026년: 전력망 사이버 공격, 수바우키 회랑 긴장, 국회 국정조사 |
